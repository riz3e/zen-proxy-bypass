# Proxy Exclude — сайты без прокси (для Zen / Firefox)

Ситуация: локальный прокси-клиент (v2rayN/NekoRay, sing-box, Clash и т.п.) включён
постоянно, и браузер ходит в интернет только через него. Но некоторым сайтам прокси
только мешает (банк страны проживания, локальные сервисы, скорость). Это расширение
добавляет одну кнопку: клик — и конкретный сайт начинает ходить напрямую, все
остальные — как обычно, через прокси.

## Как работает

- Перехватывает все запросы браузера через официальный API `browser.proxy.onRequest`.
- Домен из списка обхода (или локальный адрес) → соединение **напрямую**.
- Всё остальное → через настроенный прокси (по умолчанию `socks5://127.0.0.1:10808`).
- Запись `example.com` покрывает весь домен, включая поддомены (`www.example.com`,
  `api.example.com`). С `www.` в попапе автоматически убирается.
- `localhost`, `127.x`, `10.x`, `192.168.x.x`, `172.16–31.x.x`, `169.254.x.x`,
  `*.local` — всегда напрямую, независимо от списка.
- Тумблер «Расширение активно» на паузе полностью возвращает браузер к его обычным
  настройкам прокси (как будто расширения нет).
- Для SOCKS5 включён `proxyDNS` — имена сайтов резолвятся на стороне прокси и не
  уходят в DNS местному провайдеру.

## Установка в Zen

**Вариант 1 — временная (работает всегда):**
1. Открой `about:debugging#/runtime/this-firefox`
2. «Загрузить временное дополнение…» → выбери `manifest.json` в этой папке
   (или готовый `proxy-exclude-1.0.0.xpi` рядом)
3. Работает до перезапуска браузера.

**Вариант 2 — постоянная (неподписанное расширение):**
1. Открой `about:config` → принял предупреждение
2. Найди `xpinstall.signatures.required` → переключи в `false`
3. В `about:addons` → шестерёнка → «Установить дополнение из файла…» → выбери `.xpi`
4. Вернуть `true` после установки **нельзя** — расширение отвалится; оставь как есть
   или подпишись на AMO (см. ниже).

**Вариант 3 — постоянная без отключения подписей:** создать аккаунт на
addons.mozilla.org и подписать расширение «для себя» (unlisted) через
`web-ext sign` — тогда ставится навсегда с включённой проверкой подписей.

## Первый запуск

При установке сразу откроются настройки — проверь, что указано `SOCKS5 · 127.0.0.1 ·
10808` (или твои реальные тип/хост/порт), и нажми «Сохранить».

Чтобы работало в приватных окнах: `about:addons` → Proxy Exclude → «Разрешения» →
напротив «Запуск в приватных окнах» → «Разрешить».

## Если вдруг пропал интернет

- Поставь расширение на паузу тумблером в попапе — браузер вернётся к своим
  обычным настройкам прокси. Либо выключи расширение в `about:addons`.
- Проверь, что прокси-клиент запущен: если он выключен, а расширение активно,
  страницы не откроются — весь трафик уходит в неработающий прокси.

## Ограничения

- Расширение управляет только трафиком браузера. Если VPN поднят на уровне ОС
  (TUN-интерфейс, WireGuard/OpenVPN) — «выпустить» один сайт мимо сможет только
  split tunneling в самом VPN-клиенте, расширение тут бессильно.
- WebRTC-трафик проксируется по тем же правилам только начиная с соединений
  браузера; для параноидальной анонимности смотри настройки `media.peerlink`
  отдельно.

## Файлы

- `manifest.json` — манифест (MV2, Firefox-совместимый)
- `common.js` — общие хелперы (списки, домены)
- `background.js` — логика маршрутизации `proxy.onRequest`
- `popup.html/js` — окно на панели: статус сайта + тумблеры
- `options.html/js` — настройки прокси и список обхода
- `icons/icon.svg` — исходник иконки (PNG генерируются из неё)
